# شبیه‌ساز آزمایش دو شکاف تامس یانگ

[![GitHub Repository](https://img.shields.io/badge/GitHub-AmirMoYousefVand%2FDouble--slit--experiment--Simulator-181717?logo=github&logoColor=white)](https://github.com/AmirMoYousefVand/Double-slit-experiment-Simulator)
[![Latest Release](https://img.shields.io/github/v/release/AmirMoYousefVand/Double-slit-experiment-Simulator?label=release&logo=github)](https://github.com/AmirMoYousefVand/Double-slit-experiment-Simulator/releases)

**داشبورد اپتیک موجی کلاسیک و مکانیک کوانتومی**

آزمایشگاه دوزبانه (فارسی / English) که آزمایش دو شکاف یانگ را از دو دیدگاه شبیه‌سازی می‌کند:
حل موجی فراونهوفر (Fraunhofer) به‌صورت کلاسیک، و دوگانگی موج-ذره در مکانیک کوانتومی
همراه با مونت‌کارلوی زندهٔ تشخیص ذرات — به‌علاوهٔ ارائهٔ تعاملی تحت وب با Flask.

## امکانات

### اپتیک موجی کلاسیک
- توزیع شدت دقیق دو شکاف فراونهوفر: `I(θ) = I₀ cos²(β) sinc²(α)`
- معیارهای زنده: فاصلهٔ تورفتگی‌ها `Δy`، جدایش زاویه‌ای، زوایای بیشینه/کمینه، و تشخیص **ترتیب گمشده** (نسبت `d/a`)
- پارامترهای قابل تنظیم: طول موج `λ` (۳۸۰–۷۸۰ nm)، فاصلهٔ دو شکاف `d`، پهنای هر شکاف `a`، فاصله تا پرده `L`، ضریب شکست `n`
- ۶ پیش‌فرض آزمایشگاهی: لیزر سرخ هِلیوم-نئون، لیزر سبز یون آرگون، دیود بنفش، خط سدیم، محیط آبی، پراکندگی بالا
- رنگ‌بندی فیزیکی دقیق (نگاشت طول‌موج به sRGB بر اساس روش دن برَتون)

### مکانیک کوانتومی
- انتخاب ذره: **فوتون**، **الکترون**، **باکی‌بال C₆₀** با طول موج دِ بُرُلی واقعی
- کنترل انرژی جنبشی / سرعت در واحدهای SI و الکترون‌ولت
- **آشکارساز «کدام‌شکاف» (Which-Way)** — از هم‌نهشتی کامل موجی (D = 0) تا فروپاشی کامل تابع موج (D = 1) را تنظیم می‌کند و الگوی تداخل را از بین می‌برد
- نمونه‌گیری برداری مونت‌کارلو که هیستوگرام تشخیص را ذره‌به‌ذره می‌سازد — درست مانند فیلم‌های تاریخی رشد الگو

### نماها (۷ زبانه)
| زبانه | توضیح |
|---|---|
| پرده ۲D | صفحهٔ آشکارساز — تورفتگی‌های پیوستهٔ طیفی (کلاسیک) یا تجمع برخوردهای ذره‌ای (کوانتومی) |
| پروفیل ۱D | نمودار شدت با کیفیت بالا در Matplotlib همراه با برچسب قله‌ها |
| شماتیک | چیدمان میز نوری به‌همراه موج‌ها و اختلاف مسیر `Δr` |
| راه‌اندازی ۳D | دستگاه آزمایش سه‌بعدی تعاملی با چرخش ماوس و بزرگ‌نمایی غلتک |
| محاسبات | استخراج گام‌به‌گام روابط با جایگذاری عددی زنده |
| تاریخچه | ارائهٔ کلاسی متحرک دربارهٔ آزمایش ۱۸۰۱ یانگ + آزمون |
| راهنما | آموزش تعاملی تمام قابلیت‌های نرم‌افزار |

### بستهٔ خروجی گرفتن
- **CSV** — مجموعهٔ دادهٔ علمی ۲۲ ستونه
- **DOCX** — گزارش آزمایشگاهی با فرمول‌های قابل‌ویرایش OMML در ورد
- **OBJ/MTL** — مدل CAD موج با بافت ۱۰۲۴×۵۱۲ صفحه
- **PNG** — تصاویر ۳۰۰ DPI (پروفیل، راه‌اندازی، پرده، شماتیک، محاسبات)
- **ZIP** — بستهٔ کامل شامل همهٔ موارد بالا

### زبان‌ها و پوسته
- رابط کاربری کاملاً فارسی و انگلیسی، با رندر صحیح راست‌به‌چپ (نشانهٔ Unicode RLM، فونت وزیرمتن، `arabic-reshaper` و `python-bidi`)
- پوستهٔ تیره و روشن

### ارائهٔ وب
- سرور Flask که یک اسلاید‌شوی HTML5 واکنش‌گرا با ریاضیات LaTeX (MathJAX)، تصویرسازهای بومی تعاملی و آزمون چهارگزینه‌ای ارائه می‌کند

## نصب

```bash
git clone https://github.com/AmirMoYousefVand/Double-slit-experiment-Simulator.git
cd Double-slit-experiment-Simulator

python -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate

pip install -r requirements.txt
```

## اجرا

### رابط گرافیکی دسکتاپ

```bash
python main.py
```

### ارائهٔ وب

```bash
python -m web.app
# سپس مرورگر را به http://127.0.0.1:5055 باز کنید
```

### مجموعهٔ آزمون‌ها

```bash
python test_simulator.py
```

این مجموعه، تحلیل فراونهوفر، تشخیص ترتیب گمشده، طول موج دِ بُرُلی، فروپاشی ناشی از
آشکارساز، کارایی مونت‌کارلو، رنگ‌سنجی، همهٔ قالب‌های خروجی، ثبت فونت‌ها، تمام نماها،
جداسازی دقیق رشته‌های دوزبانه و مقداردهی اولیهٔ کامل رابط گرافیکی را پوشش می‌دهد.

## ساختار پروژه

```
├── main.py                  # نقطهٔ ورود رابط گرافیکی
├── config.py                # ثابت‌های فیزیکی (CODATA 2018)، پیش‌فرض‌ها، تنظیمات UI
├── test_simulator.py        # مجموعهٔ جامع آزمون و راستی‌آزمایی
├── physics/
│   ├── classical_engine.py  # حل‌کنندهٔ اپتیک موجی فراونهوفر
│   ├── quantum_engine.py    # چگالی احتمال، هم‌نهشتی، نمونه‌گیر مونت‌کارلو
│   └── particle_types.py    # خواص فوتون / الکترون / باکی‌بال
├── ui/
│   ├── main_window.py       # پوستهٔ CustomTkinter (کناری + ناحیهٔ ۷ زبانه‌ای)
│   ├── components/          # پنل‌های کنترل، معیارها و کوانتوم
│   ├── views/               # 2D، 1D، شماتیک، 3D، محاسبات، تاریخچه، راهنما
│   └── content/             # محتوای ارائه و آموزش
├── utils/                   # خروجی‌گیری، بومی‌سازی، فونت‌ها، رنگ‌ها، آمار
├── web/                     # اپ ارائهٔ وب با Flask (static و templates)
├── assets/                  # فونت‌ها (وزیرمتن، Space Grotesk) و تصاویر تاریخی
└── tools/                   # اسکریپت‌های دریافت تصاویر
```
